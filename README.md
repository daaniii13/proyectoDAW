Como clonar el repositorio en local paso a paso:

git clone https://github.com/daaniii13/proyectoDAW.git

cd proyectoDAW

git checkout main-dev

composer install

npm install

symfony server:start


Herramientas (necesarias):
XAMPP 8.2.12
Composer 2.9.5
Symfony CLI 5.16.1
Git Bash
Node.js 24.14
